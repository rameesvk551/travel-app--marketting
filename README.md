# Wayon

Marketing website for Wayon, a travel business workspace for CRM, booking management, trip operations, suppliers, payments and a branded website builder.

## Development

```sh
npm install
npm run dev
```

Build the static site with `npm run build`. Astro writes the output to `dist/`.

The demo and contact forms open a prefilled email draft to `hello@wayon.travel`. They do not submit to a backend or store form data.
